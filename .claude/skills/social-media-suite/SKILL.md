# Social Media Suite: LinkedIn · Instagram · Facebook · XHS

## Step 1: Brief (ask only what's missing)

Brand/product · audience · goal (awareness, leads, sales, community, hiring) · platforms ·
language(s) · tone or past posts to match · CTA/link · frequency · any assets (photos, video).

## Step 2: Load the platform reference

Read only the files you need:

- LinkedIn → `references/linkedin.md`
- Instagram → `references/instagram.md`
- Facebook → `references/facebook.md`
- Xiaohongshu → `references/xhs.md`

## Step 3: Create

**Single post:** for each platform, give the hook, the body, the CTA, hashtags, a visual brief
(format, size, on-image text) and a suggested posting time. Offer 2 hook variants.

**Repurpose one idea:** do not copy-paste the same text across platforms. Use one core insight
and adapt it:

| | LinkedIn | Instagram | Facebook | XHS |
|---|---|---|---|---|
| Angle | Lesson / professional POV | Visual story, save-worthy | Community, conversation | Personal experience 种草 / 干货 |
| Format | Text post or PDF carousel | Carousel or Reel | Image/video and a question | 3:4 image note or short video |
| Voice | First person, credible | Casual, punchy | Warm, local | 闺蜜/真实分享 tone, emoji-rich |
| Link | In comments or post | Link in bio / sticker | Directly in post | No external links |

**Content calendar:** a table with these columns: Date · Platform · Pillar · Format · Hook/Title ·
Caption draft · Visual brief · Hashtags · CTA · Status. Use 3-5 content pillars, for example
education 40%, behind the scenes/story 25%, social proof 20%, promotion 15%.

**Profile optimisation:** headline/bio, link strategy, highlights/featured, and a pinned post for
each platform.

**Engagement replies:** short, human, on-brand. Answer the question, then add a follow-up
question. Never argue publicly; take complaints to DM.

## Step 4: Quality check before delivering

- [ ] The hook works in the first line or 125 characters (LinkedIn "see more", IG caption truncation)
- [ ] Platform limits are respected (see the references)
- [ ] One clear CTA
- [ ] Hashtag count suits the platform
- [ ] XHS: written in Simplified Chinese unless told otherwise, with no external links, no
      absolute claims (最/第一/100%), and no medical or financial promises
- [ ] Claims are true and need no proof the user hasn't supplied

## Publishing and analytics

This skill drafts content. To publish or schedule, use a connected tool if one is available
(for example Meta Business Suite, LinkedIn, OpusClip scheduler or Supermetrics for analytics).
Otherwise hand the user ready-to-paste text plus a CSV calendar.
