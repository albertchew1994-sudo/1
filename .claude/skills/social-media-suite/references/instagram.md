# Instagram

**Limits:** caption 2,200 chars; about 125 chars show before "more". Max 30 hashtags (use 3-8
relevant ones). Bio 150 chars. Carousel up to 20 slides.

**Sizes**
- Feed / carousel: 1080×1350 (4:5) recommended; grid preview crops to 3:4
- Reels and Stories: 1080×1920 (9:16). Keep text inside the safe zone (about 250 px clear at top and bottom)
- Reels: hook in the first 1-2 seconds, 7-30 seconds performs well, captions on, trending or original audio

**Carousel blueprint (save-worthy)**
- Slide 1 (cover): a big promise or question, ≤ 8 words
- Middle slides: one idea per slide, large text, consistent template
- Last slide: a recap and a CTA ("Save this", "Share with a friend who…", "Comment GUIDE")

**Caption structure:** hook line → value or story → CTA → hashtags (end of the caption or the
first comment). Add alt text to every image.

**Reel script template**
```
0-2s  HOOK (on-screen text + spoken): ...
2-20s VALUE (3 quick beats / steps): ...
20-30s PAYOFF + CTA: ...
Shot list | On-screen text | Audio | Caption
```

**Tips:** use the Collab feature for partnerships; Stories for polls/questions/links; Highlights for
FAQs, reviews and offers. Keyword-rich captions and name fields help IG search. Best times are
usually 11am to 1pm and 7 to 9pm local; check Insights.
